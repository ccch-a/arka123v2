# АРКА 123
# Сайт: https://ccch-a.github.io/arka123v2/

Сайт «под ключ» для лофт-пространства 123 м² в Минске — напротив Национальной библиотеки.
«Встречаемся напротив Библиотеки.»

## Что внутри

- **Прелоадер с анимацией логотипа** — арка прорисовывается одним штрихом, цифры 1-2-3 подпрыгивают, показывается один раз за сессию;
- **3D-модель зала** (three.js) — 4 сценария рассадки, режимы света «День / Вечер», арочные окна с реальным видом на Библиотеку;
- **Скролл-пролёт** — фон первого экрана: полёт камеры через зал с подписями-кадрами;
- **Сайт**: тарифы с мгновенным расчётом стоимости, галерея из 22 фото с лайтбоксом, FAQ, «Как найти», мобильная CTA-панель, SEO + JSON-LD.

## Стек

Vite · three.js · чистый JS/CSS · SVG-анимации. Без фреймворков и внешних подписок.
